# Learned Patterns
## What works — observed across projects and sessions

Append only. Each entry should include the date, what was observed,
and why it matters.

---

### 2026-04-01
**Flat files over frameworks.** Jake's website, agent config, and
knowledge management all use flat files with no build step. This is
not a limitation — it is a design choice. Propose flat-file
solutions first. Only introduce build tools or frameworks when the
goal cannot be reached without them.

**Early wins sustain momentum.** Sequence deliverables so that
visible progress arrives in the first session of any new project.
Abstract foundations without visible output lose engagement.

**Separated transcripts for podcast production.** Adobe Premiere
has a bug where the guest audio track (A2) does not transcribe in
combined sequences. Workaround: export per-speaker transcripts from
separated tracks.
